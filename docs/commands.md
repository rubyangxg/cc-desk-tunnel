# Claude 会话指令

升级到 v0.4.5 后，在会话输入框输入 `/` 打开命令列表。输入名称筛选，方向键选择，Tab 或点击补全；填写参数后按 Enter 发送，Shift+Enter 换行，Esc 关闭列表。

| 指令 | 用途 |
| --- | --- |
| `/goal <目标>` | 将目标交给 Claude 原生目标功能 |
| `/compact` | 压缩当前上下文 |
| `/plan` | Claude 原生规划指令 |
| `/review` | 审查代码 |
| `/init` | 生成项目说明 |
| `/context` | 查看上下文占用 |
| `/usage`、`/cost` | 查看用量 |
| `/help` | 查看 Claude 帮助 |

例如：

```text
/goal 修复项目中的错误，并让现有测试全部通过
```

菜单从当前服务端 Claude Code 读取，只显示它实际提供的命令；不同版本、账号配置或插件可能有不同列表。列表里的“刷新命令与额度”用于重新读取。命令输出和目标状态显示在会话中；客户端不会自行编造目标循环，也不会将 `/goal` 改写成普通提示词。

切换账号或项目后，若原生上下文尚未衔接，请先发送一条普通消息，再使用指令。自定义命令来自服务端 Claude 配置；本机项目中的 `.claude/commands` 不会自动上传到服务器。

验证包括界面补全和发送测试、离线 CLI 的真实 SDK 传输测试；各命令的具体行为由安装的 Claude Code 决定。

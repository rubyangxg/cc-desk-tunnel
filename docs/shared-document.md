# 共享 Markdown 文档

在 **设置 → 共享文档** 中直接编辑并保存，也可以导入 UTF-8 编码的 `.md` 或 `.markdown` 文件（最大 512 KB）。导入只替换编辑器里的草稿，点击“保存”才生效，不修改导入源文件。清空内容再保存即可清除共享资料。

文档位于客户端数据目录的 `shared/reference.md`，页面“保存位置”显示完整路径。同一台电脑、同一系统用户的所有账号、连接窗口、项目与会话使用这同一份文件；换账号或跨服务器续接不会复制或清空它。不会自动同步到另一台电脑。

保存后，Claude 在需要服务器信息、凭据等资料时，会通过本机执行通道按需读取最新内容；无需把全文粘进每条消息。也可以直接说“请先查看共享文档”。正在运行的任务不会因保存而自动重发消息。页面切换保留未保存草稿，退出或重载客户端前需先保存。

这是普通明文文档，不是加密密码库。内容由你自行组织，Claude 读取的片段可能进入模型上下文和工具记录。服务端提示要求只读取相关部分、尽量在本机脚本内使用凭据且不输出值，但不能保证任意格式的密码自动隐藏。文档内容本身不代表授权执行连接、部署等操作。

## 升级和兼容

先升级服务端，再升级客户端至 0.4.15，并重新连接。服务端会在普通会话和原生终端的运行提示里告知共享文档入口；客户端给本机执行通道设置 `CC_DESK_TUNNEL_SHARED_DOCUMENT` 环境变量。所有账号共用入口，不修改账号的全局 `CLAUDE.md`。

协议仍为 19。旧客户端没有环境变量或尚未保存文档时，Claude 会照常继续；新客户端可以编辑文档，但旧服务端不会自动提示 Claude 查阅它。

## 保存冲突

两个窗口同时编辑时，后保存的窗口会检查已读版本；如果文件已变更，会保留草稿并提示重新载入，不覆盖另一窗口的内容。先复制自己的草稿，再重新载入、合并并保存。

保存使用锁和临时文件替换。异常退出如果留下 `reference.md.lock`，请退出这台电脑上的全部客户端，再删除该锁文件；保留 `reference.md`。确认文件内容后重新打开客户端编辑。

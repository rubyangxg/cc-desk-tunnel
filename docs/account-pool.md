# 单代理服务的 Claude 账号池

一台代理服务保存多个由你本人使用的 Claude 账号。Windows 客户端只连接这一台服务；服务端按额度选择账号，项目文件继续留在本机，图形会话历史保存在同一台服务上。

## 开始使用

1. 升级配套服务端和客户端。连接后侧栏出现 **Claude 账号池** 即表示服务端支持此功能。旧服务仍可连接，但不能通过只升级客户端获得服务端账号池。
2. 原有登录自动显示为“原有 Claude 账号”，无需重新导入凭据。
3. 点 **添加 Claude 账号**，设置名称，点 **登录账号**，用对应账号完成官方授权。每个新增账号有独立登录目录，不会覆盖原有账号。
4. 点 **检测全部账号**，确认登录和额度正常后开启 **自动接力**。
5. 选择“5 小时快重置优先”，或选择“自定义顺序”并上下调整账号卡片。

同一个浏览器可能保留上次的 Claude 登录。授权前确认官方页面上的账号正确，必要时使用不同浏览器配置或隐私窗口。

## 页面与调度

- 顶部显示可调度账号数、已登录账号数和当前模式；每张卡片显示 5 小时 / 周额度、重置时间、检测异常及启停状态。
- 新任务按所选策略选择账号。已有会话优先继续使用当前可用账号，避免无必要地重建原生上下文。
- 只有明确收到 **5 小时额度耗尽** 的信号才自动接力。普通网络错误、登录故障和工具异常不会被当作额度耗尽。
- 未登录、停用、检测失败、额度未知、检测超过两分钟、5 小时或全账号周额度耗尽的账号不参与自动调度。检测恢复后可重新参与；手动停用需要手动开启。
- 任务运行时可用账号不足会暂停，每 30 秒检测是否恢复；所有账号的常规检测间隔为一分钟。检测不发送模型提示词。停止按钮可结束等待。
- 关闭自动接力后使用固定账号。会话上方可以在空闲时手动换账号；“Claude Code”设置页可以按账号修改原生设置。
- 登录、退出与该账号的运行互斥。账号池是同一用户的多个登录配置，不是不同租户之间的安全隔离。

## 会话如何继续

同一图形会话的项目绑定和可见历史一直保留。切到另一个账号后，服务端创建新的 Claude 原生会话，将最近用户任务、对话与工具进度交给它；不传递思考内容，不复制账号凭据。交接文本有长度上限，因此不等于复制完整原生上下文、长期记忆或提示缓存。

工具还未结束、结果未知、后台任务未结束，或有未确认送达的补充消息时，不自动重放任务。原账号额度恢复且仍被选中时，继续原账号的原生会话。服务重启、用户停止或永久断连会结束当前等待，不自动重放未确认的操作。

旧的“多代理服务切换”作为兼容模式保留。不同服务器的历史仍各自独立；此功能不会把另一台旧服务器的历史自动搬到新服务。建议选择保存主要历史的服务器升级，再将其他账号通过官方授权加入它。

## 从试用包升级已有 Docker 部署

在同一次 Actions 构建中下载 `windows-x64` 和 `server` 两个产物。解压 `server.zip`，将里面的 `cc-desk-tunnel-server-X.Y.Z.tar.gz` 上传到服务器；将下面路径替换为实际文件路径。在原程序安装目录执行：

```sh
cd /opt/cc-desk-tunnel
sudo bash deploy/manage.sh upgrade --from /path/cc-desk-tunnel-server-X.Y.Z.tar.gz
```

升级前结束运行中的任务，并按[部署手册](../deploy/README.md)备份数据。命令会重建容器，保留现有数据目录、登录、连接地址、证书和服务凭据。自定义安装目录或部署配置请继续使用原来的路径与 `PROXY_DEPLOY_CONFIG`。不要重新初始化部署。

安装同一构建的 Windows 安装包后，连接原来的服务地址即可。Actions 试用产物不会自动成为 GitHub 正式发布，因此“一键安装最新 Release”不一定能取得这次试用版本。

## 存储与验证范围

- 账号标签、开关、顺序和额度观测保存在 `PROXY_DATA_DIR/sessions.sqlite`；已有默认账号沿用原配置目录。
- 新增账号的官方登录与原生记录位于 `PROXY_DATA_DIR/accounts/<账号 ID>/config/`，目录权限为 `0700`。完整备份需要同时保存代理数据与原有 Claude home。
- 每次启动 CLI 和读取官方 SDK 历史都指定对应账号环境；SDK 文件操作通过独立 Worker 环境运行。新增账号不继承原服务的提供方 API key。
- 自动测试覆盖账号隔离、优先顺序、同会话切换、额度恢复等待与取消、未知工具结果不重放，以及桌面 / 窄屏界面。集成测试使用真实 SDK 协议配合离线 CLI，不代表已完成真实订阅额度耗尽的线上验收。

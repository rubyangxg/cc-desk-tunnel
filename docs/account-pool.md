# 单代理服务的 Claude 账号池

一台代理服务保存多个由你本人使用的 Claude 账号。Windows 客户端只连接这一台服务；服务端按额度选择账号，项目文件继续留在本机，图形会话历史保存在同一台服务上。

## 开始使用

1. 升级配套服务端和客户端。连接后侧栏出现 **Claude 账号池** 即表示服务端支持此功能。旧服务仍可连接，但不能通过只升级客户端获得服务端账号池。
2. 原有登录自动显示为“原有 Claude 账号”，无需重新导入凭据。
3. 点 **添加 Claude 账号**，设置名称，点 **登录账号**，用对应账号完成官方授权。每个新增账号有独立登录目录，不会覆盖原有账号。
4. 点 **检测全部账号**，确认登录和额度正常后开启 **自动接力**。
5. 选择“5 小时快重置优先”，或选择“自定义顺序”并上下调整账号卡片。

同一个浏览器可能保留上次的 Claude 登录。授权前确认官方页面上的账号正确，必要时使用不同浏览器配置或隐私窗口。

## 页面与调度

- 顶部显示可调度账号数、已登录账号数和当前模式；每张卡片显示 5 小时 / 周额度、重置时间、检测异常及启停状态。
- 新任务按所选策略选择账号。已有会话优先继续使用当前可用账号，避免无必要地重建原生上下文。
- 只有明确收到 **5 小时额度耗尽** 的信号才自动接力。普通网络错误、登录故障和工具异常不会被当作额度耗尽。
- 未登录、停用、检测失败、额度未知、检测超过两分钟、5 小时或全账号周额度耗尽的账号不参与自动调度。检测恢复后可重新参与；手动停用需要手动开启。
- 任务运行时可用账号不足会暂停，每 30 秒检测是否恢复；所有账号的常规检测间隔为一分钟。检测不发送模型提示词。停止按钮可结束等待。
- 关闭自动接力后使用固定账号。会话上方可以在空闲时手动换账号；“Claude Code”设置页可以按账号修改原生设置。
- 登录、退出与该账号的运行互斥。账号池是同一用户的多个登录配置，不是不同租户之间的安全隔离。

## 按项目等待重置后继续

右键侧栏项目，勾选 **额度重置后自动继续**（默认关闭，需要 v0.4.4 或更新的客户端和服务端）。

- 该项目的会话遇到 5 小时额度耗尽后，按服务端取得的重置时间等待，随后向原账号、原生会话发送一次 `continue`。
- 开启账号池自动接力时，优先使用其他可用账号；没有可用账号时再等待当前账号重置。只想等待原账号时，关闭账号池自动接力。
- 运行中或 CLI 正在等待额度时开启也生效。关闭此项目开关或点击停止，会取消已安排的等待。
- 设置按设备和项目目录保存，重连后保留。等待期间保持客户端运行、电脑不休眠、执行通道在线；服务重启、退出客户端或长时间断线会结束当前等待，重新连接后需手动继续。
- 无法取得重置时间、工具结果未知或后台任务未结束时，不会自动发送。已经结束的旧任务不会因开启开关而重新运行。

## 会话如何继续

同一图形会话的项目绑定和可见历史一直保留。切到另一个账号后，服务端创建新的 Claude 原生会话，将最近用户任务、对话与工具进度交给它；不传递思考内容，不复制账号凭据。交接文本有长度上限，因此不等于复制完整原生上下文、长期记忆或提示缓存。

工具还未结束、结果未知、后台任务未结束，或有未确认送达的补充消息时，不自动重放任务。原账号额度恢复且仍被选中时，继续原账号的原生会话。服务重启、用户停止或永久断连会结束当前等待，不自动重放未确认的操作。

旧的“多代理服务切换”作为兼容模式保留。不同服务器的历史仍各自独立；此功能不会把另一台旧服务器的历史自动搬到新服务。建议选择保存主要历史的服务器升级，再将其他账号通过官方授权加入它。

## 从试用包升级已有 Docker 部署

在同一次 Actions 构建中下载 `windows-x64` 和 `server` 两个产物。解压 `server.zip`，将里面的 `cc-desk-tunnel-server-X.Y.Z.tar.gz` 上传到服务器；将下面路径替换为实际文件路径。在原程序安装目录执行：

```sh
cd /opt/cc-desk-tunnel
sudo bash deploy/manage.sh upgrade --from /path/cc-desk-tunnel-server-X.Y.Z.tar.gz
```

升级前结束运行中的任务，并按[部署手册](../deploy/README.md)备份数据。命令会重建容器，保留现有数据目录、登录、连接地址、证书和服务凭据。自定义安装目录或部署配置请继续使用原来的路径与 `PROXY_DEPLOY_CONFIG`。不要重新初始化部署。

安装同一构建的 Windows 安装包后，连接原来的服务地址即可。Actions 试用产物不会自动成为 GitHub 正式发布，因此“一键安装最新 Release”不一定能取得这次试用版本。

## 存储与验证范围

- 账号标签、开关、顺序和额度观测保存在 `PROXY_DATA_DIR/sessions.sqlite`；已有默认账号沿用原配置目录。
- 新增账号的官方登录与原生记录位于 `PROXY_DATA_DIR/accounts/<账号 ID>/config/`，目录权限为 `0700`。完整备份需要同时保存代理数据与原有 Claude home。
- 每次启动 CLI 和读取官方 SDK 历史都指定对应账号环境；SDK 文件操作通过独立 Worker 环境运行。新增账号不继承原服务的提供方 API key。
- 自动测试覆盖账号隔离、优先顺序、同会话切换、额度恢复等待与取消、未知工具结果不重放，以及桌面 / 窄屏界面。集成测试使用真实 SDK 协议配合离线 CLI，不代表已完成真实订阅额度耗尽的线上验收。

## 跨服务器保留会话并继续

客户端保存多个代理服务配置，每个服务仍管理自己的 Claude 账号池。两台服务器可以分别登录两个账号和一个账号；项目文件继续留在同一本机目录。

- **手动交接**：会话顶部选择“续接到其他服务器…”。当前任务、原生终端及其他本机任务须先结束，未发送草稿和排队消息须先处理。目标服务按自己的账号池策略选账号。
- **自动接力**：在“账号与额度”开启统一“自动接力”（单服务器仍使用原有开关）。各服务须记住连接凭据。本服务先在自己的账号池中接力；没有可用账号、进入额度等待后，客户端探测其他服务的完整账号池。找到可用服务后，先请求原服务结束额度等待并确认任务终止，再连接目标服务继续。
- **升级要求**：自动结束新版服务的额度等待需要源服务声明 `cross-server-handoff` 能力。旧服务可在任务结束后手动交接；不会将普通停止请求当作安全交接来结束未知状态的原生任务。协议号不变，通过能力协商启用新增命令。
- **统一显示**：完整已记录历史分页读取后保存在此客户端的 IndexedDB，按服务器和账号标记来源。目标服务器创建新的原生会话，但保留标题、项目、模型和权限设置；界面接上原有对话，自动提交一次带近期上下文的 `continue`。原生上下文和提示缓存不承诺完整继承。
- **重新打开**：重启客户端后仍可在目标会话读取之前的历史。从原服务打开旧会话会显示“前往当前会话”，避免在旧分段误发任务。导出会话包含先前各服务器的历史。清除客户端应用数据会删除本机合并记录；各服务器仍保存各自原始记录。
- **交接保护**：工具结果未知、后台任务未完成、消息送达不确定或队列未处理时拒绝交接。创建或发送确认丢失后暂停并提示检查历史，不自动重试；客户端重启也不会重放交接请求。修改过的目标地址不会自动继承旧连接的会话。
- **统计与连接**：计费和实时状态仍来自实际运行的服务器及账号，历史显示不会把旧服务器事件写入目标服务器或重复计费。客户端仍只保持一个活动执行隧道；多个本机任务同时运行时不会自动断开它们进行跨服务器切换。

跨服务器历史属于当前电脑，不是多客户端云同步；登录凭据不会随会话转移。目标服务器上需要预先登录可用的 Claude 账号。历史分段暂不支持原地编辑后分叉，可在当前会话发送新消息修订任务。

### 交接中断后的手动恢复（0.4.39）

- 队列显示“跨服备份”但没有成功续接时，在原会话点 **恢复原队列**。先确认其他服务器没有正在执行的续接任务；恢复后消息仍暂停，可以查看、删除或继续队列，不会立即重发。
- 如已找到续接会话，使用 **前往当前会话**，不要恢复原队列。
- “消息送达状态未确认”会附上操作提示。展开上一轮记录核实进度，再点输入框右下角 **继续**；需要跨服务器交接时，确认弹窗后携带进度续接。自动接力不会代替用户确认；工具结果未知或后台任务未结束仍会阻止交接。
- 恢复冻结队列需要来源服务端和 Windows 客户端均升级到 0.4.39 或更新兼容版本。请先升级参与接力的服务端，再升级客户端；旧服务端会显示需要升级的提示。


## 全部代理账号与会话总览（0.4.16）

- “账号与额度”在同一网格展示已配置代理的账号，并标明服务器、额度和本服务器记录的等价费用。同名账号按服务器区分。
- 保存各代理的连接凭据后自动读取；“检测全部账号”同时检测各服务器。检测失败保留上次卡片并标为离线，不参与调度。
- 统一开关同时设置各服务内部接力与客户端跨服务器接力。服务拒绝或离线时会报告未完成配置；部分开启状态单独提示。优先继续使用当前服务的可用账号，无可用账号后再自动连接其他服务。
- 远程账号的“参与调度”可直接操作；“连接管理”自动切到该服务的账号页进行登录或退出。后台读取和启停操作不会切换执行隧道；连接管理遇到当前运行任务会先提示。
- 侧栏展示已配置代理的所有已知会话。首次自动读取需要记住凭据；临时离线保留目录，正文仍需连接来源服务器读取。点击会话自动连接来源，使用原会话历史，不会自动复制或重发任务。
- 删除代理配置或修改地址、证书后隐藏旧来源目录。清除客户端应用数据会清除本机目录；各服务器的原始会话不受影响。
